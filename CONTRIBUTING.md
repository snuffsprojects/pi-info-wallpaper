# Contributing

Thanks for helping improve Pi Info Wallpaper.

1. Open an issue for substantial behavioural or visual changes.
2. Create a focused branch and keep unrelated changes separate.
3. Run `python3 -m unittest discover -v` and the shell syntax checks from the README.
4. Do not include hostnames, addresses, credentials or generated personal wallpapers.
5. Explain which Raspberry Pi OS or Linux desktop environment you tested.

Bug reports should include the operating system, desktop environment, command used,
and relevant error output. Please redact private hostnames and IP addresses.
